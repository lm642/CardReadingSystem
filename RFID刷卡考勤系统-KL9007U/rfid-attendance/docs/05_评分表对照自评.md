## 四、答辩现场建议（演示脚本）

按这个顺序演示，节奏最稳：

1. **先跑逻辑自检**（不依赖硬件，证明逻辑对）
   ```bash
   python attendance.py --selftest      # 14/14 通过
   python uhf_reader.py                 # 9/9 协议自检通过
   ```
2. **再跑硬件读卡**（证明真能读卡）
   ```bash
   python read_test.py                  # 打印读卡器信息 + 实时卡号
   ```
3. **启动主程序**，演示：
   - 绑定一张卡 → 刷卡签到 → 提示成功；
   - （可临时把间隔改成 0 分钟）再刷 → 签退；
   - 刷一张没绑定的卡 → 陌生卡提示；
   - 快速连刷同一张卡 → 只记一条。
4. **异常演示**：刷卡过程中拔掉读写器 → 显示"正在重连"，插回自动恢复。
5. **现场改需求**：进【设置】把间隔改成 45 分钟，保存生效 → 说明规则可配置。
